# DiskLens

Анализатор папок: показывает, какие файлы и разделы занимают больше всего места.

Приложение для Windows с русским интерфейсом, работающее локально без аккаунта и сети.

## Возможности

- Сканирование выбранной папки во вторичном потоке с возможностью отмены.
- 200 самых больших файлов, распределение по расширениям и папкам первого уровня.
- Количество недоступных объектов и просмотр первых ошибок.
- CSV-отчёт и открытие расположения выбранного файла в Проводнике.
- Только анализ: приложение не удаляет и не перемещает файлы.

## Запуск

Скачайте `DiskLens.exe` из [Releases](https://github.com/modeAlohadance/disk-lens/releases/latest).
Распаковывать или устанавливать Python для EXE не нужно. Сборка не подписана цифровым сертификатом.

Из исходников: Python 3.10+ с Tcl/Tk, затем `py -3 app.py` или двойной щелчок по `run.bat`.
Для обычного запуска внешние Python-библиотеки не требуются.

## Разработка

```powershell
python -m unittest discover -s tests -v
python app.py --smoke
```

`--smoke` создаёт интерфейс с временным хранилищем и закрывает его; пользовательские данные не меняются.
Для сборки EXE запустите `build.bat`: он создаст локальное виртуальное окружение и установит PyInstaller.
Результат появится в `dist/`. EXE собран для Windows x64.
Владелец репозитория также может запустить Actions → Build Windows release: workflow проверит приложение, соберёт EXE и опубликует новую версию с контрольной суммой. Уже опубликованные версии не перезаписываются.

## Устройство

`core.py`: обход через scandir, ограниченная очередь крупнейших файлов, агрегация и отмена.
`app.py`: интерфейс и обмен результатами через очередь. Ссылки и Windows junction/reparse points пропускаются.
Показывается логический размер файлов, а не физически занятые кластеры; hard links могут учитываться повторно.
Результаты хранятся в памяти; CSV сохраняется только по запросу. Отменённый отчёт помечается как неполный.
